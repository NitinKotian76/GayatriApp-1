Gayatri Invoice System
======================

**GayatriApp** is a custom invoicing and inventory management web application for GSPBL. It is built with `Django`_ and server-rendered templates, using `HTMX`_ for progressive enhancement where appropriate.

.. _Django: https://www.djangoproject.com/
.. _HTMX: https://htmx.org/

The live application code lives under ``gayatri_invoice/gayatriapp/`` in the repository. This Sphinx project documents architecture, setup, and how the main packages fit together.
